# Guardian Agent Runtime v0.5.0

This release includes the observed-outcomes pilot, its frozen protocol, case-level results and a two-page research note. The pilot compares tool acknowledgements with destination observations on a file worker and a simulated joint. Guardian and a simple checker agreed on all 126 decisions. Each correctly resolved the 52 claims predicted to be answerable and left 74 unknown.

Install with `python -m pip install guardian-runtime-assurance==0.5.0` using Python 3.12 or later. Run `guardian-study --output pilot` to regenerate the report and signed examples. The release includes a versioned adapter contract, linked v2 evidence and an optional Inspect AI task.
