# Research questions

1. Which authorization and safety properties can be enforced independently of an untrusted agent?
2. How much benign utility is lost as runtime constraints become stricter?
3. Which bypasses arise from composition between individually authorized tools?
4. How should capability delegation preserve required constraints, purpose, revocation, nonce, and invocation budgets?
5. How much execution-evidence integrity is gained by combining a signed hash chain with a signed terminal checkpoint?
6. Can adversarial findings be minimized and converted into durable regression cases without overfitting to one observed route?
7. Which guarantees fail under signing-key compromise or a lower-level tool that violates its declared contract?
8. Which guarantees require stronger isolation, hardware roots of trust, or formal verification beyond this reference implementation?
